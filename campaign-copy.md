# Deck Rats — Campaign Preview

**A first-person pirate adventure · In development**

Sail a changing Caribbean. Explore a growing archipelago, command sailing ships, face shifting weather and build your name as a pirate in Deck Rats, an in-development first-person adventure.

## Project description

Deck Rats is an in-development first-person pirate adventure set across a Caribbean archipelago. Set out from the tavern, sail between distinctive island regions, and contend with weather that moves across the sea. Ship handling, crew systems, exploration and combat are being built together around a living world in Unreal Engine 5.8.

This preview leads with recent in-game development captures and separates them from engine environment studies and concept artwork. It presents the project in progress and does not imply a release date, finished feature set or ecosystem endorsement.
